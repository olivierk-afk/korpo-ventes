⚡ Automatisation mensuelle (Supabase Edge Function + Resend) Prêt

Une fois la fonction send-monthly-statements déployée sur Supabase, les relevés partent automatiquement ou en 1 clic ci-dessous.

Configuration serveur 100 % automatique (3 minutes dans Supabase) :
  1. Créez un compte gratuit sur resend.com et copiez votre clé API (re_...).
  2. Dans Supabase > Edge Functions, créez une fonction nommée send-monthly-statements, ajoutez le secret RESEND_API_KEY, et collez le code ci-dessous.
  3. Activez l'extension pg_cron dans Supabase pour déclencher cette fonction automatiquement le dernier jour de chaque mois à 18h00.
